# healthcare-booking-app

This project is a simple web-based healthcare appointment system created for the INFS3023 CI/CD Pipelines and DevSecOps tutorial.

## Features

- Basic login page
- HTML and CSS structure
- GitHub Actions CI pipeline
- Simulated automated testing
- Basic DevSecOps reflection

## Purpose

The purpose of this project is to demonstrate Git workflow, collaborative development, automated CI checks, and DevSecOps awareness using GitHub Actions.
